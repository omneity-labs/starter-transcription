# Demo audio recording

A5.6-second excerpt from **WIKITONGUES: Anass speaking Moroccan Arabic**, by Wikitongues and Anass Sedrati. [Source](https://commons.wikimedia.org/wiki/File:WIKITONGUES-_Anass_speaking_Moroccan_Arabic.webm) · [CC BY-SA4.0](https://creativecommons.org/licenses/by-sa/4.0/).

The audio is excerpted from25.0–30.6s of the original. The text and word timings are selected from recorded Daktilo and Sawalign output for the longer source recording. They are not a separate API response for this short file. The reviewed text adds punctuation and a line break; it does not change the recognized words.
